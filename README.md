A [make.fun](https://make.fun/c/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) bounty entry: one line, at most 200 characters, roasting a smart fridge.

`main.ts` writes the roast to `/output/entry.txt`:

> My smart fridge's ice maker filed a bug report on me: 'User opens the door 47 times a day. Recommend therapy.'

Run it with `node main.ts` (Node 22+).
